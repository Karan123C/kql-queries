# KQL Detection Queries — Microsoft Sentinel

A collection of KQL queries used for SOC alert triage and threat detection 
in Microsoft Sentinel.

## Categories
- **Identity** — Entra ID, failed logons, privilege changes
- **Email** — Exchange Online, mailbox forwarding, phishing indicators
- **Network** — FortiGate, port scans, suspicious traffic
- **Endpoint** — Windows Event logs, process creation, PowerShell

## Tools & Log Sources
Microsoft Sentinel | Entra ID | Exchange Online | 
FortiGate | Windows Security Events | AWS | Duo

## Purpose
Built as part of hands-on SOC L1 investigation experience.
